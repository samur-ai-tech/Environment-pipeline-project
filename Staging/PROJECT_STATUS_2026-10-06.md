## 1. What the project is

One pipeline: geographic source package (OSM + DEM) → Houdini HDA `GeoCity_city_v015_*` builds terrain, 4 ground masks (Ground/Steep/RoadBed/BuildingPad), building pads, placement points → official Houdini Engine for Unreal cooks it in the editor → native Unreal meshes are instanced via `unreal_instance` → Bake → named save of the area map. A sealed Python lifecycle in `Content/Python/` (manifest `Staging/SystemCompletion_2026-10-04/geocity_runtime_manifest.json`, current seal `258469e1`) drives Generate/Regenerate, gates, roads (RoadBLD), ground material/Grass, Bake, ledgers and named saves.
